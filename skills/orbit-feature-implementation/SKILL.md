# ORBIT feature implementation

1. Read AGENTS.md and feature requirements.
2. Inspect current implementation and working tree.
3. State plan, scope, risks and test commands.
4. Create a scoped branch/worktree if appropriate.
5. Implement the smallest complete vertical slice.
6. Add unit/integration/e2e tests, failure handling and cancellation.
7. Update contracts, migrations, docs, requirements traceability and feature status.
8. Ask for independent review when security, tenant, data or external actions are involved.
9. Report exact changed files and test evidence. Mark limitations honestly.
