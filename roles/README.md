# ORBIT role library

> **Document baseline:** ORBIT 1.0.0-draft (2026-11-08). Earlier version labels are historical unless explicitly marked current.

This directory contains reusable role charters for an IDE agent or ORBIT orchestrator. These are not real employment records. The founder/CEO role is a human accountability role. Other roles are virtual specialist workflows that may be run by one model, several models or a human contributor. They do not independently bind the company.

Start with `ROLE_REGISTRY.yaml`; load only the specialist charter relevant to the current task. A role charter does not grant runtime permissions. Tool access is determined by the central policy engine and the user's explicit grants.


v0.6 added roles: Repository Operations / Upstream Integration Engineer, Integration / Connector Engineer, Local Model Runtime / Inference Engineer, and Benchmark / Performance Engineer. These are AI-assisted role definitions only.
