# Third-party notices and source provenance

The ORBIT v1.1 developer toolkit contains original ORBIT-specific Python code, shell launchers, configuration, tests and documentation. It has no third-party Python runtime dependencies. The six upstream repositories listed in `configs/upstream-candidates.lock.json` are research candidates only: no upstream source code, assets, model weights or skill packages are bundled in this toolkit.

The root `LICENSE` files of those candidate repositories were observed during the 2026-11-08 pin audit. This observation is not legal approval and is not a substitute for inspecting nested licenses, notices, dependency licenses, copyright headers, trademarks, model terms or dataset terms at the exact pinned revision.

Before importing or redistributing any upstream material:

1. Verify the exact commit and file hashes.
2. Read root and nested LICENSE, NOTICE, COPYING and per-file notices.
3. Resolve dependency and asset license closure.
4. Record source URL, commit, path, SHA-256, license evidence and modifications.
5. Update the SBOM and third-party component register.
6. Obtain security, QA and human maintainer review.

Do not remove upstream attribution, copyright, LICENSE, NOTICE or provenance to make product branding appear original.
