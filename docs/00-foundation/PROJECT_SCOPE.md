# Project Scope

> **Document baseline:** ORBIT 1.0.0-draft (2026-11-08). Earlier version labels are historical unless explicitly marked current.

## In scope
Chat/workspace; auth and workspace authorization; provider adapters/router; agent planner/executor; typed tools/policy/approvals; durable tasks; research/citations; file parsing/RAG; Playwright browser worker; sandboxed Git/code worker; user-controlled memory; skills/routines; bounded multi-agent; MCP/connectors; self-hosting and telemetry.

## Excluded from MVP
Foundation-model training; unrestricted host automation; bypassing CAPTCHA/login/paywall/rate limits; automatic purchases/transfers; unapproved external messaging/publishing; unreviewed plugin marketplace; unbounded agent swarms; enterprise SSO/multi-region; broad Tor/dark-web collection; Kubernetes absent a measured need.

Every capability requires explicit scope, permissions, quotas and failure behavior.

## ORBIT v0.2 alignment

The v0.2 product baseline adds optional native desktop access through a paired Local Desktop Node. It does not change ORBIT’s core mission or move desktop control into the first MVP. Keep product objectives focused on verified, safe task completion.
