# Product Vision

> **Document baseline:** ORBIT 1.0.0-draft (2026-11-08). Earlier version labels are historical unless explicitly marked current.

ORBIT is a personal/team AI workbench where agents understand goals, use tools, operate isolated computers, collaborate and return verified outcomes under human control.

Principles: outcome-first; visible execution; evidence before confidence; user-controlled permissions and memory; provider freedom; durable tasks; extensible contracts; honest capability labels.

Strategic position: do not market an API wrapper as a new foundation model. Compete through execution reliability, openness, privacy, self-hosting, provider choice, transparent cost and reviewed workflow reuse.

Differentiation hypotheses (not yet market-validated): task timeline/evidence; local-first execution; strong recovery; cost/capability-aware routing; safe skills/plugins; developer-first repository workflows. Validate with real users and comparative benchmarks.

## ORBIT v0.2 alignment

The v0.2 product baseline adds optional native desktop access through a paired Local Desktop Node. It does not change ORBIT’s core mission or move desktop control into the first MVP. Keep product objectives focused on verified, safe task completion.
