# Glossary

> **Document baseline:** ORBIT 1.0.0-draft (2026-11-08). Earlier version labels are historical unless explicitly marked current.

**Agent:** configured AI execution identity. **Task:** durable requested outcome. **Run:** one task attempt. **Step:** persisted unit of work. **Tool:** typed capability. **Tool Gateway:** only path to external effects. **Policy Engine:** validates actor/workspace/tool/target/arguments/approval. **Approval:** expiring authorization for one exact action. **Workspace:** tenant/project data boundary. **Artifact:** durable task output. **Evidence:** source supporting a claim. **Memory:** provenance-tagged user-controlled context. **Skill:** versioned reviewed workflow. **Routine:** scheduled/event-triggered skill. **MCP:** Model Context Protocol. **Sandbox:** isolated execution environment. **Idempotency key:** retry deduplication key. **Outbox:** event persisted atomically with state change before publication.

## ORBIT v0.2 alignment

The v0.2 product baseline adds optional native desktop access through a paired Local Desktop Node. It does not change ORBIT’s core mission or move desktop control into the first MVP. Keep product objectives focused on verified, safe task completion.
