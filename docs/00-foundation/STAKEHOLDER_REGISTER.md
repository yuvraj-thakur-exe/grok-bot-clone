# Stakeholder Register

> **Document baseline:** ORBIT 1.0.0-draft (2026-11-08). Earlier version labels are historical unless explicitly marked current.

| Stakeholder | Responsibility | Need |
|---|---|---|
| Founder/product owner | Vision, risk appetite, launch authorization | Roadmap, trade-offs, cost |
| CTO/engineering owner | Architecture and quality | Requirements, ADRs, tests |
| Contributors | Implement and maintain | Setup, contracts, coding rules |
| End users | Direct agents and approve actions | Trust, evidence, control |
| Workspace admin | Membership, integrations, limits | Access policy, audit |
| Security reviewer | Threat/incident review | Threat model and telemetry |
| Extension developer | MCP/tools/skills | Stable contracts and permissions |

## ORBIT v0.2 alignment

The v0.2 product baseline adds optional native desktop access through a paired Local Desktop Node. It does not change ORBIT’s core mission or move desktop control into the first MVP. Keep product objectives focused on verified, safe task completion.
