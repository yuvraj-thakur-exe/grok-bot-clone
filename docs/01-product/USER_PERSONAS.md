# User Personas

> **Document baseline:** ORBIT 1.0.0-draft (2026-11-08). Earlier version labels are historical unless explicitly marked current.

- **Individual builder:** wants research, repo understanding, code changes and automation; values flexibility/low cost.
- **Research analyst:** needs multiple sources, citations, file collections and exportable reports; values evidence/freshness.
- **Team operator:** needs repeatable routines/integrations; values approvals/audit.
- **Self-hosting admin:** needs data control, secrets, backup, upgrades and usage limits.
- **Plugin developer:** needs stable SDK, manifests, permission contracts and test harness.

## ORBIT v0.2 alignment

The v0.2 product boundary adds native desktop control as a later optional device capability. It is separate from web browser automation and code execution, and requires pairing, runtime capability visibility and user-controlled pause/revoke.
