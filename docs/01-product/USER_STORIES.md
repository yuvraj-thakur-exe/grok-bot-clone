# User Stories

> **Document baseline:** ORBIT 1.0.0-draft (2026-11-08). Earlier version labels are historical unless explicitly marked current.

US-001 create workspace boundary. US-002 chat with streamed response. US-003 research with source-supported claims. US-004 query uploaded docs with page references. US-005 inspect and cancel task. US-006 approve/reject exact external action. US-007 inspect repo in sandbox. US-008 review diff/test before PR. US-009 inspect/edit/delete memory. US-010 save reviewed workflow as skill. US-011 restrict tools/domains per workspace. US-012 configure provider key without committing it.

## ORBIT v0.2 alignment

The v0.2 product boundary adds native desktop control as a later optional device capability. It is separate from web browser automation and code execution, and requires pairing, runtime capability visibility and user-controlled pause/revoke.
