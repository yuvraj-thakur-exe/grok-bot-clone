# Examples

> **Document baseline:** ORBIT 1.0.0-draft (2026-11-08). Earlier version labels are historical unless explicitly marked current.

- `agent-desktop-mcp.json` shows the upstream `agent-desktop mcp` stdio configuration for a trusted local developer environment only. It is not a production policy configuration or a permission grant.
- `docs/04-system-design/DESKTOP_COMMAND_ALLOWLIST.yaml` is the proposed ORBIT-side curated command allowlist. Commands are not live until implemented, tested and enabled by policy.
